# 运营分析指标实现

日期：2026-11-09。

## 已实现

- 新增管理员接口 `GET /api/admin/analytics`，支持近 7 / 30 / 90 天；接口也支持 1–90 个完整日期的自定义区间。北京时间截至昨日，对比前一段等长区间。
- 6 个核心指标：新增业务用户、已答题用户、已答题面试、24h 面试完成率、24h 正常报告率、场均平台成本（首 24h）。返回当前值、上期值、相对变化或百分点差，以及口径说明。
- 真实日趋势与上期曲线、会话转化漏斗、D1 / D7 答题留存、面试类型拆分、供应商与模型成本拆分、规则生成的数据解读。
- 从类型分析和模型成本进入明细时携带同一日期、业务账号范围、模式、类型或供应商筛选。原有查询默认行为保持兼容，新增 `end_exclusive=true` 使用不含结束时刻的范围。
- 用户管理可标记测试账号，修改经过管理员鉴权并写入审计日志。统计排除管理员和测试账号，保留禁用账号的历史行为；修改测试标记会重新计算历史统计。

## 计算边界

- 活跃口径改为持久化回答，不再用登录时间替代。按用户、会话去重；跳过等回答文本也计入“已答题”，不据此判定回答质量。
- 转化漏斗按区间内创建、已完整观察 24h 的同一批会话计算，逐步取交集。首页已答题人数和场次按回答发生时间统计，二者口径不同，在页面说明。
- 完成率为成熟创建会话中在首 24h 内结束且状态为 finished 的比例。未满 24h 会话显示待观察，不作未完成处理。
- 正常报告与兜底报告分别记录。`score_reports.generation_status` 为 success / fallback / unknown；历史记录默认 unknown，不推断成功。已完成样本有未知结果时不计算整体正常报告率。
- 场均成本为成熟会话首 24h 内已记录的平台成本除以该群会话数；没有平台用量样本时显示未知。页面显示有记录的会话数，提示自填 Key、供应商未返回 usage 等覆盖边界。
- 期间平台成本单独按调用发生时间统计，包含未关联会话的记录；和按创建会话分群的场均成本分开展示。输入与输出按 Token 和配置价格估算，不代表供应商账单实付。
- 留存按首次答题日分群，D1 / D7 为指定自然日再次答题。仅在观察日完整结束后进入分母。
- 比率变化用百分点，数量和金额用相对变化；上期为零显示“由 0 增长”，无样本与零分开处理。

## 数据层与兼容升级

新建 `AdminAnalyticsRepository` 和 `AdminAnalyticsService`，沿用 Controller / Service / Repository 分层。查询仅读取身份 ID、时间、状态和用量，不读取简历、回答、报告正文；批量取数，不按会话逐条查询。

新增 `users.is_test` 和 `score_reports.generation_status`，由现有 `ensure_schema()` 自动兼容补列。补建注册、会话、回答及用量时间索引；兼容部分旧表存在的升级环境，重复执行不会清空数据。

修复 `chat_json()` 在 JSON 解析失败时同一尝试重复计数的问题：解析通过后才记成功，每次尝试只记一次成功或失败。报告成功状态由引擎执行结果决定，不信任模型自行返回的标志。

## 验证

- 后端相关测试：94 通过、3 跳过。覆盖鉴权、测试账号排除与审计、北京时间边界、零值 / 空值、固定观察窗、报告兜底、关联去重成本、跨周期成本、留存成熟度、重试计数、旧库兼容升级及现有面试状态机。
- 前端现有测试：41 通过；TypeScript 与生产构建通过。
- 本地真实 HTTP 验证 7 / 30 / 90 天统计和携带范围的会话、用量明细接口。
- 浏览器验证自动本地预览、周期切换、成本趋势切换和带日期范围的会话明细跳转。

当前本地库没有业务面试和平台用量记录，页面展示真实空态；测试样本使用隔离 SQLite，没有写入本地业务库。

## 后续数据能力

跨重启的日调用失败率、日 P95、重试成本及业务节点成本仍需要持久化调用尝试和节点关联。当前页面说明这一边界，没有把进程内监控数包装成日统计。当前窗口内的精简事实记录在服务层聚合，数据量较大时可改为数据库日汇总；留存首次答题仍需查询历史回答。
