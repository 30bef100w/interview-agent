# 深问运营后台后端重构

本次范围为深问运营后台的 Python / FastAPI 后端。参考 Databuddy 后端的 Controller → Service → Repository 分层、管理员边界和会话排查流程，落到深问现有的数据模型与 JWT 权限体系。

## 模块职责

| Databuddy 参考 | 深问实现 | 职责 |
| --- | --- | --- |
| Admin Controller / Request DTO | `backend/app/api/admin.py`、`backend/app/schemas/admin.py` | HTTP 请求校验、统一鉴权、响应契约 |
| Admin Service | `backend/app/services/admin_service.py` | 用户操作、额度、统计、会话查询、事务审计 |
| 审核业务 | `backend/app/services/admin_review_service.py` | 错标队列、标签修改、题库编辑 |
| Conversation Repository | `backend/app/repositories/admin.py` | 筛选、稳定排序、分页计数和批量聚合 |
| 会话 Trace 查询 | `backend/app/services/admin_trace_service.py` | 合并规划、引擎和门禁日志 |
| AdminAuthInterceptor | Router 级 `Depends(require_admin)` | 新增运营路由自动校验管理员身份 |

管理员身份取自当前数据库用户；每次请求重新校验登录、禁用状态与角色。所有写操作的操作者由认证上下文取得。已有 JWT、密码重置后的令牌失效机制继续使用。用户列表和详情只返回自有 Key 的布尔状态。

## 接口

旧接口路径和原有响应字段保留。列表额外返回 `limit` / `offset`，无数据时返回空 `items` 和正确 `total`。重复注册的题库目录、题目查询和 apply 路由已移除。基础分页、用户、会话、问答、日志、平台用量响应均在 OpenAPI 中定义。

| 方法 / 路径 | 功能 / 筛选 |
| --- | --- |
| `GET /api/admin/stats` | 用户、活跃、面试、平台成本和错误汇总 |
| `GET /api/admin/users` | 用户名或 ID 搜索 `q`，`status=active/disabled/admin` |
| `GET /api/admin/users/{id}` | 用户详情、最近面试、额度流水 |
| `PATCH /api/admin/users/{id}` | 禁用、角色、绝对额度设置 |
| `POST /api/admin/users/{id}/quota` | `delta` 增减额度与备注 |
| `POST /api/admin/users/{id}/reset-password` | 重置密码 |
| `POST /api/admin/users/{id}/clear-llm-key` | 清除自有 Key，切回平台配置 |
| `GET /api/admin/logs` | `level`、`source`、`user_id`、`q`、时间范围和分页 |
| `GET /api/admin/usage/platform` | `user_id`、`session_id`、`model`、时间范围和分页 |
| `GET /api/admin/sessions` | **新增**，会话 ID、用户 ID / 用户名、状态、模式、类型、岗位、企业、时间范围 |
| `GET /api/admin/sessions/{id}` | **新增**，会话详情、实际问答数、调用成本、报告 |
| `GET /api/admin/sessions/{id}/messages` | **新增**，按题序合并问题与回答；`role=user/assistant`，服务端分页 |
| `GET /api/admin/sessions/{id}/trace` | **新增**，规划 / 引擎 / 门禁时间线 |
| `GET /api/admin/tag-mismatches[/stats]` | 错标队列及统计 |
| `POST /api/admin/tag-mismatches/{id}/resolve` | 修正 / 忽略审核记录 |
| `GET /api/admin/tag-mismatches/{id}/question` | 对应题库条目或审核快照 |
| `POST /api/admin/tag-mismatches/{id}/apply` | 修改标签或删除题库条目 |
| `GET /api/admin/question-bank/catalog` | 岗位、企业、场景和分类目录 |

旧的 `/api/observability/metrics`、`/api/observability/sessions/{id}/trace` 仍有效。旧 Trace 入口与新运营入口复用同一业务服务。

列表 `limit` 为 1–200，默认 50；`offset` 非负。不存在的用户、会话和审核记录返回 404。无登录返回 401，普通用户 / 禁用账号返回 403。无效参数返回 422，业务约束不满足返回 400，绝对额度设置遇到并发变化返回 409。

示例：

```http
GET /api/admin/sessions?username=alice&status=finished&start_time=2026-11-01T00:00:00%2B08:00&limit=20&offset=0
Authorization: Bearer <管理员 JWT>
```

时间范围字段为 `start_time` / `end_time`，包含两个边界。带偏移时间统一转为 UTC 比较；不带偏移按北京时间解释。日活、今日新增审核、今日 / 本月面试均按 `Asia/Shanghai` 划分自然日 / 月。数据库时间仍采用原有 UTC 存储约定，旧响应时间格式保留。

会话 `cost_yuan` 为该会话的全部模型调用成本；平台用量接口只统计平台 Key 调用，其 `total_cost_yuan` 是**所有符合筛选条件的记录**之和，不受分页影响。会话消息中 `assistant` 为面试问题，`user` 为回答；旧问题表没有创建时间，因此问题消息 `created_at=null`，按题序与问题 ID 排序。

## 一致性和查询

- 用户和会话列表均采用批量聚合，查询次数不随当前页条目数线性增长。筛选条件复用于列表和总数。
- 数据库修改和管理员审计在同一事务内提交。审计插入失败时额度和额度流水一并回滚。
- 额度增减使用数据库原子更新，避免两个请求基于旧余额相互覆盖。超过余额的扣减返回 400，零增减也拒绝。额度设置采用条件更新，并为支持的数据库加行锁。
- 保留不能禁用自己、不能取消自身管理员身份的规则。
- Trace 文件每次请求只读一次，使用有界行缓存，忽略损坏行 / 非对象记录。无 Trace 文件的会话返回空日志，不影响会话查询。

## 实际边界

- 新增会话 API 已可调用，现有前端没有新增会话管理入口。
- Trace 和引擎指标仍来自当前实例本地文件 / 内存；多实例部署需另行接入集中日志。历史 Trace 中未携带偏移的时间按北京时间排序。
- 题库内容仍存 JSONL 文件，编辑复用现有备份和替换流程；文件写入与数据库审核记录不具备跨存储的原子事务。数据库提交失败时应检查备份并对账，后续可迁移为数据库内容版本。
- 本次数据库验证使用 SQLite；PostgreSQL 的行锁行为尚未在真实 PostgreSQL 环境验收。
