- 状态：本地代码与运行快照已完成，未部署服务器；没有将36,033条initial标注宣称为逐题复核。
- 默认运行图从旧9,000题ZIP改为 `backend/graph/mgkg-45033-active-v1.zip`。完整45,033条离线图不改写；运行快照仅保留active节点与关系，包含23,005道有图连接的题、8道逐题确认的通用行为题。4,322道题符合八股叶子题池条件。原企业、岗位、答案及出处属性保留。
- 修复空结果误判成功：项目图返回零题时抛出 `EmptyGraphResult`，实际执行旧B路；八股叶子池为空、被质量筛选清空或检索异常时退回原岗位/技能题池，并排除本场已选项目题。
- 保留原始父子结构的非叶子标记，避免过滤draft子节点后把父知识点误当成八股叶子。退休/未知状态不再因“不是draft”而进入默认检索。
- 无图连接题逐条记录为 `held_unlinked`，仅显式确认的行为题进入单独HR参考区；不因无边自动补技术标签或生成场景。逐题路由清单位于原离线图目录的 `runtime-v1-question-routes.jsonl`。
- 同题合并时同时合并企业来源与目标企业匹配标记，避免多个企业的相同题面被去重后丢失来源。
- 验证：发布门禁、坏哈希/无清单拒绝、生产draft拒绝、空结果降级、HR分区、实际快照五个技术入口与KG/MG双路回归。仅验证本地执行与边界，未重新宣称线上模型的相关率或LLM延迟。
- 本轮后端全量测试：346 passed、19 skipped、1 xfailed，另22个子测试通过；五个真实种子均返回100道项目候选结果，项目与八股去重、active路径和遍历预算检查通过。该项是执行回归，不是新的语义相关率评测。
