# 深问运营后台界面与本地预览

本次修复了 Tailwind 依赖缺失及旧 Webpack 缓存导致的样式失效，明确全局样式的扫描目录。更新后的后台采用浅色侧栏、统一导航和页头，概览展示真实用户、面试、成本、审核与服务状态；无数据时展示空状态。

新增面试会话列表和平台用量明细，支持筛选与分页，调用现有运营接口。用户管理、日志、运行监控、题库审核同步使用浅色样式；用户及日志时间按北京时间显示。

## 本地预览

入口：`http://127.0.0.1:57362/admin`。

在 `frontend` 运行 `npm run dev:admin`，后端仍需运行在 `127.0.0.1:8001`。当前机器已配置被 Git 忽略的 `frontend/.env.local`，使用已有本地预览账号自动建立会话；打开后台或会话失效后均无需手动填写账号。

其他机器需要自行设置以下服务端环境变量，并提供已存在且有管理员权限的本地账号：

```dotenv
DEEPASK_LOCAL_PREVIEW=1
DEEPASK_PREVIEW_USERNAME=<本地预览账号>
DEEPASK_PREVIEW_PASSWORD=<本地预览密码>
```

该入口仅在开发环境且明确启用时响应，前端和后端地址都必须为回环地址。它要求同源 Origin 和自定义请求头，使用现有后端登录与管理员校验；没有新增免鉴权的后端运营接口。账号密码仅保存在服务端环境，不写入浏览器脚本。生产环境始终返回 404，部署后仍沿用现有管理员登录流程。

## 验证

- 自动预览覆盖生产关闭、未配置、跨站请求、非本地地址、普通账号及登录失败等场景。
- 样式回归检查实际编译全局 CSS，确保布局工具类存在、原始 Tailwind 指令已消除。
- 浏览器中退出账号后重新访问 `/admin`，已验证自动进入；核心运营接口返回正常。

当前预览连接本机 SQLite 数据库；只有本地预览用户、没有真实面试记录，因此列表及费用为对应的实际空数据。
